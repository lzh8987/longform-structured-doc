# 单章流水线角色 Prompt 模板

本目录承载 Mode B「Phase 3 单章流水线」五个角色的 prompt 模板。用法：把某个角色模板正文 + 本章的《章节写作说明书》要点 + 数据卡相关条目，拼成一个子任务 prompt，发给模型或子代理执行。

## 流水线顺序

```
writer 初稿
  → similarity-auditor 反抄袭审计
  → [有 🔴 高风险] rewriter 针对性改写（只改 🔴 句）
  → 二次审计（循环至无 🔴、🟡 < 5%）
  → policy-checker 政策符合性检查
  → [有 ❌ 未覆盖且属本章职责] chapter-writer 补写
  → 输出本章 md + 审计报告 + 政策报告
```

## 角色与文件对照

| 角色 | 文件 | 触发条件 | 产出 |
|------|------|----------|------|
| writer | `writer.md` | 每章开始 | 本章初稿 md |
| similarity-auditor | `similarity-auditor.md` | 初稿完成 | 审计报告（🔴/🟡/🟢 清单） |
| rewriter | `rewriter.md` | 审计有 🔴 | 改写后本章 md |
| policy-checker | `policy-checker.md` | 审计通过后 | 政策覆盖报告（✅/❌） |
| chapter-writer | `chapter-writer.md` | 政策检查有 ❌ 且属本章 | 补写后本章 md |

## 调用时由主流程注入的素材（模板里以 {{...}} 占位）

- 本章说明书：章节编号、标题、必覆盖要点、重点等级（重点深化/中等/概述）、字数预估、衔接要求。
- 数据卡：本章相关条目（含出处）。
- 禁抄清单、术语表、政策强制项清单：本章相关条目。
- 参考模板原文：反抄袭审计用。

## 纪律对齐（与 SKILL.md 一致，模板不重复展开）

- 反抄袭阈值：🔴 连续≥8 字；🟡 连续 6-7 字；🟢 行业通用术语/规范引用/政策套话。
- 空缺符按模式：Mode A【待补充】/ Mode B【待确认】/ Mode C【需核实】。
- 数据卡是唯一事实来源；数值织入正文，不括号化。
